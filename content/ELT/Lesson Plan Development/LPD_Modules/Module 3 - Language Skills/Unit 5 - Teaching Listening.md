## I. Strategies in Listening

### 1. Cognitive strategies:

- Mental activities related to comprehending and storing input in working memory or long-term memory for later retrieval
  - Comprehension processes: Associated with processing linguistic + non-linguistic input
  - Storing + memory processes: Associated with storing linguistic + non-linguistic input in working memory / long-term memory
  - Using + retrieval processes: Associated with memory access, to be readied for output

### 2. Metacognitive strategies:

- Conscious/unconscious mental activities that perform an executive function in management of cognitive strategies
  - Situation assessment
  - Monitoring
  - Self-evaluating / Self-testing

## II. Pre-While-Post

### 1. Pre-stage

- Students predict possible words + phrases they might hear
- Write down predictions + words in first language

### 2. While-stage

#### a. First listen

- During the listening, underline/circle words or phrases that they have predicted correctly, write down new information they hear.

#### b. Pair process-based discussion

- Compare what they have understood so far + explain how they arrived at the understanding
- Underline parts that caused confusion / disagreement -> Make notes of parts that will require special speculation in the second listen.

#### c. Second listen

- Listen to controversial areas + note new information they may hear

### 3. Post-stage

- Discussion to confirm comprehension before discussing with students the strategies they reported using.
