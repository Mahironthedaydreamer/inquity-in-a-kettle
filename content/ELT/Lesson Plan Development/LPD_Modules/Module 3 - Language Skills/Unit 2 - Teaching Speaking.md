## II. Correcting Mistakes in a Speaking Lesson

### 1. Feedback during accuracy work

#### a) Showing incorrectness

- Done if Ss are able to correct themselves when the problem has been pointed out.
  - Repeating
  - Echoing
  - Statement + Question
  - Expression
  - Hinting
  - Reformulation

#### b) Getting it right

- T can ask Ss to correct each other

### 2. Feedback during fluency work

#### a) Gentle correction

- T may have to invervene if communication breaks down during a fluency activity
- Needs to prompt Ss forward if they can't think of what to say
- May offer a form of correction at the right time to point out a language feature
  - Reformulate what S has said
  - Use other accuracy techniques to show mistakes
- Less disruptive than accuracy-based feedback because T uses it gently, does not move on to a "getting it right" stage
- Overuse may lead to interruption

#### b) Recording mistakes

- T acts as observer, watching and listening to Ss to give feedback (pos/neg)
  - T should write down points/charts of categorization

| Grammar | Words/Phrases | Pronunciation | Appropriacy |
| ------- | ------------- | ------------- | ----------- |
|         |               |               |             |

- T can record Ss' language performance on audio or video tape
- T can divide Ss into different groups for different things

#### c) After the event

- T gives feedback to class
  - May give assessment (how well S did, getting Ss to tell most difficult/easiest parts)
  - Can put recorded mistakes on board -> Ask Ss to recognize pattern and put it right
  - Can write both correct and incorrect words, phrases, sentences on board -> Ask Ss to decide which is which
  - Can write individual notes to Ss
