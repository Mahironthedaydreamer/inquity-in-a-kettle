## I. Definition of test

- Method of measuring a person's ability, knowledge or performance in a given domain
- Any procedure used to measure a factor / assess certain abilities
  - Refers to a measurement instrument designed to elicit a specific sample of an individual's behavior

## II. Different types

| Types          | Definiton                                                                                                                                                                                                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Achievement    | - Measures how much of a language someone has learned **with reference to a particular course of study / program of instruction**<br>- End of course -> Advancement decisions<br>- Specifications:<br>	- Objectives<br>	- Importance<br>	- Task employed<br>	- Practicality<br>	- Extent towards formative washback |
| Proficiency    | - How much of a language a person has learned<br>	- Not based on specific textbooks or syllabus<br>	- Can be taken at any time<br>	- Measures general competence                                                                                                                                                    |
| Placement      | - Place students at an appropriate level in program / course<br>	- Before course starts<br>	- Not based on textbook<br>	- Practical, short<br>	- Generalized                                                                                                                                                        |
| Integrative    | - Combine many elements for completion of task<br>	- Combination of language elements<br>	- Simultaneous use of grammar + vocabulary<br>	- Integration of skills<br>	- Focus on overall language ability                                                                                                            |
| Discrete-point | - Measures knowledge of individual language items<br>	- Based on theory of languages consisting of different parts and skills<br>	- Tests parts and skills separately                                                                                                                                               |
| Prognostic     | - Predict how well one is likely to do in a language course                                                                                                                                                                                                                                                         |
