## I. Definition

- Typically administered at the end of a unit / grading period and evaluate a student's understanding
  - via comparing achievement against a class, district, or nationwide benchmark and standard.

## II. Key characteristics of summative assessment

| Characteristics      | Key words                             |
| -------------------- | ------------------------------------- |
| Purpose              | Document proficiency                  |
| Time to conduct      | Post-instruction                      |
| Teacher role         | Plan, administer, record performance  |
| Student involvement  | Limited                               |
| Student motivation   | Performance-oriented                  |
| Emphasis on learning | Knowledge, comprehension, application |
| Level of specificity | General, group-oriented               |
| Structure            | Rigid, structured, formal             |

## III. Key considerations in planning classroom summative assessment

### 1. What will result in high-quality assessments?

- Appropriate learning targets
- Assessment methods matched with learning targets
- Reliability / precision
- Validity
- Fairness / Equity

### 2. Will the sampling of content be appropriate?

- Test Blueprint:

### 3. Will the number and length be appropriate?

- Decision reliant on **how many assessments to give** and **how long each should be**:
  - Student age
  - Length of class periods
  - Types of questions

### 4. Should textbook/publisher/testing company assessment be used?

- Quality control
- Compliance to instruction
- Cognitive levels assessed
- Use with caution
- Combine with teacher-made items

### 5. How should students be prepared?

- Teach assessment-taking and testwiseness skills
- Familiarize test length, format, and types of questions
- Teach to the test (do not teach the test)
- Share the assessment blueprint
- Review before the assessment
- Tell students when the assessment is scheduled and how long it will take to complete
- Make sure students have the technical skills needed to be proficient with digitally administered tests

### 6. When should the assessments be scheduled?

- Avoid distracting days
- Instructional / Assessment map
- Announce in advance

### 7. When should assessments be constructed?

- Well in advance of testing date
- Identify evidence before teaching
- Finalize before administering
