## Definition:

- Display data over a period of time, showing how trends, patterns, or values change over Months, Years, or Decades

## Common types:

- Line graphs, Bar charts, tables,..

## Key focus:

- Trends, changes over time, fluctuations, peaks and troughs.

## Language focus:

- Increase

## How to approach:

- Start and end of time periods
- Observe overall trends increase, decrease, fluctuations,..
- Highlight significant points (highest, lowest values, sudden changes)
- Compare different time intervals

## Analyze with time period:

| **Introduction**          | Paraphrase and describe what the diagram shows          |
| ------------------------- | ------------------------------------------------------- |
| **Overview**              | Summarize key trends and patterns without specific data |
| **Body 1**                | Analyze first group's key trend with supporting data    |
| **Body 2**                | Analyze second group's key trend with supporting data   |
| **Conclusion (Optional)** | Restate overall trends                                  |

## Logical grouping

- Similar trends
  - steady increase
  - fluctuated
  - remained stable
- Performance
  - higher values
  - lower values
- Patterns over time
  - grew early -> declined
  - started low but significant increase

trend types:
upward
downward

fluctuation

Golden rule: One dominant principle (Key feature)
Fracsion
Stability
Magnitude
Time
Direction
Level

Strats:

- By Time
  - Multiple lines change direction simultaneously
    - Early -> Later
- By Direction
  - Trends oppose each other
    - Increase -> Decrease
- By Level
  - Clear gap between high-value and low-value categories
    - Leaders -> Followers
- By Magnitude
  - Direction is the same, but speed differs
    - Dramatic -> Moderate
- Stability
  - Mix of chaotic fluctuations and steady lines
    - Volatile -> Stable
