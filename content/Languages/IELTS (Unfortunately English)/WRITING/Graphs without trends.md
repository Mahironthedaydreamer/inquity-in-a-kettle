## I. Key Features

- Focuses on:
  - Comparisons
  - Rankings
  - Proportions and quantities
- Common formats:
  - Bar charts
  - Pie charts
  - Tables

## II. Task Requirements

- Summarize, select and report **main features**
- Compare **where relevant**
- **DO NOT** describe trends

## III. Strategies

### 1. To meet Task Response:

- Identify **main features**
- Include a **clear overview**
- Group data **logically**
- Make **relevant comparisons**
- Select **key figures** rather than listing all data
- Use data **accurately and selectively**

### 2. To ensure Coherence + Cohesion:

- Clear structure
  - Introduction
  - Overview
  - Detailed paragraphs
- Direct comparisons
- Apply linking devices accurately
- Linear flow: Name -> See -> Explain -> Complete

### 3. Guide Table:

| Response Part    | Type of information needed                                                             | What to look for in the graph                                                      | Guiding Questions for interpretation                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **INTRODUCTION** | - What is shown?<br>- Who / What is compared?<br>-  Unit of measurement                | - Chart type (bar / pie / table)<br>- Categories & groups<br>- % / number / amount | - What does the chart illustrate?<br>- Who / what is being compared?<br>- What is being measured?<br>- Is there any time reference?                          |
| **OVERVIEW**     | - Overall patterns<br>- Main contrasts<br>- Extremes (highest/lowest)                  | - Categories that stand out<br>- Clear differences between groups                  | - What stands out immediately?<br>-Which category is generally the highest?<br>- Which is the lowest?<br>- Do different groups show different main problems? |
| **PARAGRAPH 1**  | - First main comparison group<br>- Key similarities / differences<br>- Supporting data | - Related categories that can be grouped together                                  | - Which data can be grouped logically?<br>- How do groups differ here?<br>- Which figures best support this comparison?                                      |
| **PARAGRAPH 2**  | - Remaining comparison group<br>- Contrasting pattern<br>- Supporting data             | - Categories not previously covered                                                | - What important comparison is left?<br>- How does this differ from Para 1?<br>- Which figures best highlight this contrast?                                 |

## IV. Common mistakes to avoid

- Increase / Decrease
- Writing no overview / including no numbers in the overview
- Listing all figures without grouping
- Overusing "higher than" structures
- Failing to paraphrase numbers and percentages
- Making comparisons without clear reference points
